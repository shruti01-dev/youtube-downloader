# YouTube Downloader

Self-hosted YouTube video & playlist downloader. Works on PC, LAN, and phone.

## Features

- Single video and playlist download
- Quality: Best, 1080p, 720p, 480p, Audio MP3
- H.264 MP4 (plays in Films & TV)
- Per-user download history on LAN

## Setup

```bash
pip install -r requirements.txt
python app.py
